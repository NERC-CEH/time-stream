# 1.1.0

This release adds a new dynamic alternative-data infilling method, a helper for renaming the time column, and
simplifies the public API by replacing enums with string literals. It also includes routine dependency updates.

## Features

### Infilling

- **`AltDataDynamic`** - a new alternative-data infill method that derives a *dynamic* correction factor from data
windows either side of each gap, rather than a single static factor.

### Core

- **`TimeFrame.rename_time_column()`** - rename the time column on a `TimeFrame` while preserving its temporal
properties.

## Changes

- Public API enums (e.g. time anchor, closed interval, missing criteria, duplicate options, alignment) have been
replaced by `Literal[...]` string values, simplifying usage.

## Maintenance

- Added automated `uv` dependency updates via Dependabot.
- Numerous dependency bumps across the project and documentation.
- Resolved deprecation warnings in Sphinx documentation builds and fixed pyright type-checking issues following
dependency updates.
