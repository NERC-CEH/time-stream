# 1.2.0

This release adds a new `nth` aggregation method for selecting a value at a fixed position within an aggregation
period or rolling window. It also includes a code fix for deprecation warnings raised by updated dependencies,
alongside routine dependency updates.

## Features

### Aggregation

- **`Nth`** - a new aggregation function that selects the value (and its timestamp) at a fixed 1-based position
within each aggregation period, e.g. always taking the reading at a particular time of day. Also usable with
`TimeFrame.rolling_aggregate()` to pull a value from a fixed position relative to each timestamp.

## Maintenance

- Updated code in the flags and infill modules to resolve deprecation warnings raised by updated dependencies.
- Added automated `uv` dependency updates via Dependabot.
- Numerous dependency and GitHub Actions bumps across the project.
