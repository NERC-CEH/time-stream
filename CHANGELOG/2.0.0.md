# 2.0.0

This release extracts the period/frequency handling into a standalone package, [`isoperiod`](https://github.com/NERC-CEH/isoperiod),
and Time-Stream now depends on it rather than shipping its own `Period` implementation. This removes `Period`
from the `time_stream` namespace and tightens the accepted duration/offset string syntax, so it is a breaking
release. Runtime dependencies have also been trimmed to just Polars, NumPy, SciPy, and `isoperiod`.

## Breaking changes

### Period moved to `isoperiod`

- The `Period` class and all period parsing/arithmetic have been removed from Time-Stream and are now provided
by the separate `isoperiod` package. Replace `from time_stream import Period` with `from isoperiod import Period`.
- `TimeFrame.resolution`, `TimeFrame.alignment` and `TimeFrame.periodicity` now return `isoperiod.Period`
objects. The public behaviour is the same; only the import path of the type has changed.
- The period exceptions have been removed from `time_stream.exceptions`: `PeriodError`, `PeriodParsingError`
and `PeriodValidationError` now live in `isoperiod.exceptions` (and re-exported from `isoperiod`).
`PeriodConfigError` has been removed entirely.

### Duration and offset string syntax

- Time components in a duration or offset string must now be preceded by `T`, following ISO 8601 strictly.
`TimeFrame(df, "time", resolution="P1D", offset="+9H")` must become `offset="+T9H"`; `"P1Y+9M9H"` must become
`"P1Y+9MT9H"`. Strings that only use date components (e.g. `"+9M"`) are unaffected.
- `Period.count()` now returns `int | None` (`None` when there is no fixed count, e.g. days in a month) instead
of `0`. Code that compared the result with `> 0` should check `is not None` first.

### Dependencies

- Removed unused runtime dependencies: `config`, `pydantic`, `isodate` and `altair`.
- `pandas`, `matplotlib` and `pyarrow` are no longer runtime dependencies. They are only used by the
documentation examples and are now in the `examples` dependency group. Installing `time-stream` no longer pulls
them in transitively.

## Changes

- API reference docstrings now contain runnable, checked examples (`>>>` doctests) in place of illustrative
snippets.

## Maintenance

- The user guide's example code has moved from `src/time_stream/examples/` to `docs/source/examples/`, so it is
no longer shipped in the wheel. Examples are executed as part of the test suite
- (`tests/time_stream/examples/test_examples.py`) and the docstring examples run under pytest's `--doctest-modules`.
- Fixed several stale period strings and a typo in the `TimeFrame` docstring examples.
- Numerous dependency and GitHub Actions bumps across the project.
