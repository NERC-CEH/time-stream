# 4.0.2

This is a small release that makes copying a `TimeFrame` faster, which speeds up every method that returns a new
TimeFrame, alongside routine dependency updates.

## Changes

### Flagging

- Copying a TimeFrame no longer rebuilds its flag systems. Flag systems can't change once they are registered, so the
copy now shares them with the original. Flag columns are still copied, and registering a new flag system or flag
column, adding or removing flags, or decoding a flag column on one TimeFrame still leaves the other unchanged.
- This makes `add_flag()`, `remove_flag()` and the `with_*` methods faster on TimeFrames with flag systems. In a
benchmark of 1,000 `add_flag()` calls on a TimeFrame with three flag systems, the time fell from about 2.6s to 1.1s.
