# 2.0.1

This is a small release that speeds up decoding bitwise flag columns. Also removes unused development dependencies,
alongside routine dependency updates.

## Changes

### Flagging

- Decoding a bitwise flag column to a list of flag names is now much faster on large datasets. Each distinct flag
value is decoded once and the result is mapped back onto the matching rows. The output is unchanged: nulls decode to
an empty list, and bits not defined in the flag system are ignored.

### Core

- Checking for duplicate timestamps is slightly cheaper when there are none.

## Maintenance

- Removed unused development dependencies: `myst-parser`, `nbsphinx` and `pyarrow`.
- Removed `coverage` and the `snowballstemmer` pin, which were already provided by `pytest-cov` and `sphinx`.
- Bumped `uv` dependencies and GitHub Actions across the project.
